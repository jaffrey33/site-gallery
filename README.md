# Portfolio Website

A modern portfolio website showcasing my recent works, ongoing projects, experiments, and creative process.

---

## Overview

This site serves as a personal digital space where I document:

- Recent completed projects
- Ongoing developments
- UI/UX experiments
- Web applications
- Creative coding works
- Future ideas and concepts

The goal is to create a clean and interactive experience that reflects both technical skills and design approach.

---

##  Features

- Responsive modern design
- Smooth animations and transitions
- Project gallery with search and tag filtering
- Featured projects shown first
- Tech stack highlights
- Links to GitHub, LinkedIn and email

---

##  Tech Stack

- Next.js 16 (App Router)
- React 19
- TypeScript
- Tailwind CSS 4

---

##  Pages

### Home (`/`)
Introduction, social links and tech stack.

### Gallery (`/gallery`)
Every shipped site and demo, searchable and filterable by tag. Project data lives in `src/data/sites.ts`.

---

##  Design Direction

- Minimalist layout
- Smooth interactions
- Modern typography
- Clean spacing
- Subtle gradients and glow effects
- Developer-focused aesthetic
